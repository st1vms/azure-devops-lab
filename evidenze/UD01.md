## Workflow completato

Descrivi in cinque-dieci righe come hai ottenuto il materiale del corso e pubblicato questa evidenza nel repository personale. Integra nella spiegazione la funzione di `git status`, `git add`, `git commit` e `git push`, senza trasformare ciascun comando in una sezione separata.

### Descrizione

Per ottenere il materiale del corso ho ricevuto il link alla repository Github dal professore, e con Github Desktop ho clonato la repository nella cartella `~/workspace`. Ho creato la mia repository personale su Github insieme ad un file `README.md` e l'ho clonata con Github Desktop in `~/workspace`, successivamente dopo aver preparato le prime cartelle e il file .gitignore nella mio workspace personale, ho utilizzato `git add` per portare le modifiche in staging, `git commit` per creare il commit, e `git push` per sincronizzare le modifiche con il remote tree. Infine ho verificato che le modifiche siano in vigore con `git status`.
